# Menyumbang kepada Penganalisis Gelombang

Terima kasih atas minat anda untuk menyumbang kepada projek ini!

## Cara Menyumbang

1. **Fork** repo ini
2. **Clone** fork anda: 
   ```bash
   git clone https://github.com/username-anda/penganalisis-gelombang.git
   ```
3. **Ciptakan branch** baharu: 
   ```bash
   git checkout -b feature/ciri-baharu
   ```
4. **Commit** perubahan: 
   ```bash
   git commit -m 'Tambah ciri baharu'
   ```
5. **Push** ke branch: 
   ```bash
   git push origin feature/ciri-baharu
   ```
6. **Buat Pull Request**

## Piawaian Kod

- Pastikan kod anda kemas dan well-documented
- Follow PEP 8 style guide untuk Python
- Test perubahan anda sebelum menghantar
- Gunakan emoji notation (contoh: `:musical_note:`) untuk emoji

## Melaporkan Isu

Sila gunakan GitHub Issues untuk:
- Melaporkan bugs
- Meminta ciri baharu
- Bertanya soalan

## Keperluan Sistem

- Python 3.7+
- FFmpeg (untuk beberapa format audio)

## Ujian

Jalankan skrip untuk memastikan tiada ralat:
```bash
python -m py_compile penganalisis-gelombang.py
```
